# Small-Signal Stability & Power-System Network Analysis

## Overview

This project presents the small-signal stability analysis of an IEEE
10-bus power system using MATLAB.

The study uses a linearized power-system model and eigenvalue analysis
to investigate system oscillatory modes and damping characteristics.

## Objectives

- Model the IEEE 10-bus power system
- Develop the linearized state-space representation
- Calculate system eigenvalues
- Identify oscillatory modes
- Calculate damping ratios
- Analyze small-signal stability
- Identify critical modes

## Tools

- MATLAB
- Power System Analysis
- Eigenvalue Analysis
- State-Space Modeling
- IEEE 10-Bus System

## Methodology

1. Develop the IEEE 10-bus network model.
2. Form the required network matrices.
3. Obtain the linearized system model.
4. Calculate the system eigenvalues.
5. Separate real and imaginary components.
6. Calculate damping ratios.
7. Analyze the oscillatory modes.
8. Identify the critical modes.

## Key Analysis

For an eigenvalue:

λ = σ ± jω

where:

- σ = real part
- ω = imaginary part

The damping ratio is calculated from the eigenvalue components.

## Results

The MATLAB simulation provides:

- Eigenvalue spectrum
- Oscillation modes
- Damping ratios
- Stability characteristics
